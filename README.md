# Netflix Clone

Netflix-inspired front end built with React, TypeScript, and Vite. The app includes:

- A cinematic marketing landing page
- Local sign-in and sign-up flows backed by React context and local storage
- A browse experience with featured hero content, searchable rows, and a title details modal
- Responsive styling for desktop and mobile

## Scripts

```bash
npm install
npm run dev
npm run build
```

## Notes

- All catalog data is mocked locally in [`src/data/catalog.ts`](/Users/gauravbal/netflix-clone/src/data/catalog.ts).
- Auth is intentionally local-only for demo purposes.
